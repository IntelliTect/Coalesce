# coalesce-vue-docs

In-app product documentation for [Coalesce](https://github.com/IntelliTect/Coalesce) applications. Markdown under `docs/` is compiled by VitePress's markdown renderer inside the app's own Vite server and drawn in a Vuetify layout.

[Read the documentation](https://coalesce.intellitect.com/topics/in-app-docs.html).
